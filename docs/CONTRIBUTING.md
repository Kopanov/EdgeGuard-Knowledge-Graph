# Contributing

This file is a **stub**. The canonical contributor guide lives at
**[`/CONTRIBUTING.md`](../CONTRIBUTING.md)** in the repo root.

The guide has one location because two copies of the same
conventions drift apart. This stub exists so that:

1. Readers landing on `docs/CONTRIBUTING.md` (e.g. via bookmarks or
   doc-internal cross-references) reach the canonical guide in one
   click.
2. There is only one file to update when contribution conventions
   change.

If you arrived here looking for the contributor checklist, dev
setup, lint/format/test commands, PR conventions, or the
documentation convention (current behavior in the present tense,
dated History entries, an appendix for data written by earlier
versions) — **→ [open `/CONTRIBUTING.md`](../CONTRIBUTING.md).**
